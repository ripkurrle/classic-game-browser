Kyrandia 2 Asset Studio — User Guide

How to explore, inspect, compose, and extract Westwood game assets

Welcome to the Kyrandia 2 Asset Studio!

This desktop application lets you explore, inspect, and export every original artwork, animation, sprite, soundtrack, and script from Westwood Studios' 1993 classic point-and-click adventure.

1️⃣
Browse & Filter

Use the top category tabs (Backgrounds, Models, Animations, Soundtracks, SFX, Palettes, Scripts) or select a specific archive (e.g. INHOME.PAK) in the archive dropdown.

2️⃣
Interactive Preview

Click any asset in the sidebar or use the Up/Down arrow keys. The viewer adapts automatically: animated canvas for WSAs, interactive SoundFont synth for MIDIs, multi-line sandbox for fonts, and script search for dialogues.

3️⃣
One-Click Export

Every asset viewer includes high-resolution export buttons (PNG snapshots, looping animated GIFs, Standard MIDI, WAV audio, or raw files). Use Batch Export Center in the top header to extract entire collections at once.

Interactive Multi-Layer WSA Scene Compositing

In Kyrandia 2, room backgrounds (.CPS) are brought to life with dynamic animation loops (.WSA). The Studio features a full scene compositor:

  • Toggle Layers: Check or uncheck individual animation layers (e.g. hearth coals, dancing faun) in the lower tray to view scenery with or without props.
  • Reorder Depth (Z-Order): Click the ▲ / ▼ buttons on layer cards to change which character or object renders in front.
  • Reposition Coordinates: Adjust X and Y offset numbers or click-and-drag directly on the canvas to reposition animations.
  • Reset to Defaults: Click "Reset Layout" at any time to instantly revert all layers back to their original game-script bytecode positions.
  • Composite Export: The "Export Scene (PNG)" and "Export Animated Scene (GIF)" buttons render the complete multi-layer composition exactly as arranged.

Westwood Bitmap Font Engine (.FNT)

Westwood's 4bpp variable-width bitmap fonts (e.g. GOLDFONT.FNT, 6.FNT, 8FAT.FNT) are powered by a live typography engine:

  • Multi-Line Sandbox: Type custom sentences in the text box (press Enter for multiple lines).
  • Quick Presets: Click presets like Game Title, Dialogue, or All Glyphs to test character sets instantly.
  • Retro Color Schemes: Switch between 🌟 Gold, ⚪ White, 🟠 Amber, 🔷 Cyan, and 🟢 Emerald palettes.
  • Typography Controls: Adjust Zoom (1x–4x), Tracking (letter spacing), and Line Spacing in real time.
  • Export Font Sheet: Generate a complete 16-column character sheet PNG for modding and graphic design.

Soundtracks (XMIDI) & Speech/SFX (VOC)

Audition Frank Klepacki and Paul Mudra's legendary soundtrack with an authentic SoundFont synthesis engine:

  • Built-In Web Audio Synth: Play .XMI sequences directly in the browser with GM soundbanks, real-time seek bar, and master volume control.
  • Standard MIDI (.MID) Export: One-click export converts Westwood multi-track XMIDI events into standard Type 1 MIDI files compatible with modern DAWs (Ableton, FL Studio, Logic).
  • Creative Voice (.VOC): Audition digitized speech dialogue and sound effects with waveform visualizer and direct 16-bit WAV audio downloads.

This project is developed for historical research, educational analysis, and digital preservation. Grateful acknowledgment is made to the following original creators and reverse-engineering pioneers:

Creators of The Legend of Kyrandia: Book Two — The Hand of Fate. Rick Gush (Director), Michael Legg & Philip W. Morrow (Engine), Louis Castle & Rick Parks (Art), Frank Klepacki & Paul Mudra (Soundtrack).

🕹️ The ScummVM Project

The engines/kyra team (Torbjörn Andersson, Eugene Sandulenko, LordHoto, Florian Klämpfl) for reverse engineering Format 80 LCW, Format 40 XOR-delta, character lighting tables (_scenePal), and DTE text dictionaries.

📚 MultimediaWiki

Mike Melanson, Kostya Shishkov, and contributors for technical specifications covering Westwood Format 80, Format 40, SHP sprites, WSA animations, CPS graphics, and COL palette ram structures.

🎼 Miles Sound System (MSS)

John Miles (RAD Game Tools / Miles Design) for the XMIDI file format specification, and the MIDI Manufacturers Association for Standard MIDI File (SMF) 1.0.

🖼️ Pillow (PIL Fork) & Web Audio

Alex Clark and Pillow contributors for imaging and export capabilities; W3C Audio Working Group for the Web Audio API enabling zero-dependency browser MIDI synthesis.

For complete license notices, technical links, format citations, and reverse-engineering repositories, see ATTRIBUTION.md and SOURCES.md in the repository root.
